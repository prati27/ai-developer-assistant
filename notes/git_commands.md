## git status - 
Shows you what's changed, what's staged, what's not — your "where am I" check

## git add . -
moves the changes from local to the stagging area.

## git add filename.py -
Stages just one specific file

## git commit -m "message" -
Takes everything staged and locks it in as a permanent snapshot, with a note describing what changed

## git push 
sends your local commits upto github

## git log --oneline
Shows your commit history — a list of all your snapshots

## git pull
Downloads any changes from GitHub down to your machine (useful if you ever code from two computers, or work with others)
